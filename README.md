# Project Name: Two-Floor Office Infrastructure
This project demonstrates basic routing, switching, and IP automation.

## 🚀 What I Learned
- How to configure a Cisco 2911 Router via CLI.
- How to set up a DHCP server to automate IP addresses.
- Troubleshooting "Request Timed Out" errors.
